# 鱼力max · 说到做到

> **鱼力max 系列（鱼有分寸）**：[活人感](https://github.com/Vegra85/astrbot_plugin_fatfish_alive) · [认 AI](https://github.com/Vegra85/astrbot_plugin_fatfish_aiguard) · [看图懂梗](https://github.com/Vegra85/astrbot_plugin_fatfish_seememe) · [法庭](https://github.com/Vegra85/astrbot_plugin_fatfish_court) · [说到做到](https://github.com/Vegra85/astrbot_plugin_fatfish_promise) —— 每个都能单独用，一起装自动让路。作者 Vegra85；跟市场上其他叫「大肥鱼」的插件无关。

一句话：机器人嘴上答应「明天提醒你」「等会帮你查」「我去睡了」，转头就忘、说完「睡了」接着聊 —— 装了它，说出口的事插件替它做到：到点用它自己的口吻去提醒（群里 @ 那个人），说了去睡就真的不回、有人一直叫才醒，没做成的下次告诉它欠着一个道歉。

## 30 秒装好

1. 插件市场搜「鱼力max」或「说到做到」→ 装 → 重启 AstrBot。
2. 默认配置就能用；最常改的几项：
   - **抽取用哪个模型**（抽取 → 抽取用哪个模型）：留空 = 对话在用的那个。只在规则筛中时才调一次，选个便宜、快、不开思考的就行。
   - **每人上限**（到点的事 → 每人同时最多挂几件 / 每天最多新加几件）：默认 5 件 / 10 件，管理员不限。
   - **约束多久、怎么叫醒**（约束 / 叫醒）：离开 45 分钟、潜水 25 分钟、白天小睡 30 分钟、夜里睡到早上 8 点；管理员 @ 两次或者 5 分钟里 3 个不同的人 @ 就醒。
   - **只在哪些群管**（总开关和范围 → 只在这些群管）：留空 = 所有群。
3. 哪里看效果：WebUI → 插件 → 鱼力max · 说到做到 → 打开页面（接下来要做的、做过的、没做成的、正在生效的约束，能取消、标做完、让它回来）；群里发 `/说到做到` 看机器人答应你的事；日志里搜 `[说到做到]`。

## 常见问题

**机器人说了「明天提醒你」，表里怎么没有？**
看日志 `[说到做到]`，每一条没记上的都写了原因：没筛中（话里既没有「提醒 / 叫你 / 帮你…」也没有他要它定时的话）、时间说得不清楚（「等会」「回头」「过两天」只当成没说时间的答应）、时间已经过了、他已经挂满 5 件、对方是别人家的 AI。记不上的那件，下一轮插件会告诉模型「没记上：……」，它自己会跟人说。

**会多花钱吗？**
机器人这句话被规则筛中才调一次模型抽取：它说了「提醒你 / 叫醒你 / 催你」；或者说了时间、又带着要替他做的事（「明天帮你问」「10 分钟后叫你」）；或者「回头 / 等会 / 到时候」+ 要做的事；或者他要它定时、它答应了；或者它说自己要去睡 / 潜水 / 不理你 / 不发表情包；或者他在改 / 取消挂着的事。「我告诉你个秘密」「记住了」「到时候再说」「你快去睡吧」这种日常的话不调，一分钱不花。到点那句再调一次（让它用自己的话说），只写一次，发不出去重试也不再调。每轮给模型的状态只在有东西可说、或者他像在要它答应什么时才加，几十个字。装了活人感的话，这些用量都记进它的省 token。

**机器人「睡着」了不回，怎么叫醒？**
管理员 @ 它两次；或者 5 分钟里有 3 个不同的人 @ 它；私聊里他 5 分钟里连发 3 条。刚说完的头 2 分钟只有管理员叫得醒（大家回一句「晚安」很正常，不算叫它）。管理员也可以在群里发 `/说到做到 叫醒`，或者在面板上点「让它回来」。叫醒它的那条会照常回，模型还会知道「N 分钟前你说了『我去睡了』然后真的去睡了，是谁叫醒的」。

**到点没发出去怎么办？**
QQ 掉线、机器人在重启、QQ 拒收：1 小时内越隔越久地再试（1、2、5、10 分钟……；QQ 没连上时先 15 秒、30 秒地看，连上了马上补），那句话只写一次、重试只重发，补上的时候模型知道晚了多久、为什么晚；过了 1 小时还没发出去，记成没做成，他下次来找机器人时告诉模型欠他一个道歉（插件不会自己跑去道歉）。明确发不了的不再试：私聊他却不是好友（群里答应的会退回群里 @ 他）、机器人在群里被禁言（知道几点解、又在 1 小时内的，到点再发一次）、机器人不在群里了 —— 直接记成没做成。开机时已经过点超过 1 小时的不补。同一件事同一个原因的日志 10 分钟一行。面板「做过的 / 没做成的」里都看得到。

**时间按哪里算？私聊管不管？**
默认按北京时间（不用装 tzdata），配置里能改成别的时区。私聊默认也管：私聊里答应的到点私聊发给他；私聊里说了「我去睡了」那个私聊就真的不回。群里答应的默认在原来的群里 @ 他，他自己说「私聊提醒我」才私聊发（不是好友发不出去时退回群里 @ 他）。

## 工作原理

**1. 从它自己说出去的话里认**（发完消息以后，在后台做，不耽误回话）

- 先用规则筛（`core/extract.py` 的 `prefilter`，就是上面「会多花钱吗」那几条）：明确的「提醒你 / 叫醒你 / 催你」；时间词 + 要替他做的事；「回头 / 等会」+ 要做的事；他要它定时、它答应了；它说自己要走 / 不说 / 不理 / 不发表情包（说对方的「你快去睡吧」、问句「你睡了吗」不算）；他有挂着的事、在说「不用了 / 改到几点」。「那就不提醒了」这种否定的不算。
- 筛中了才调一次模型，让它把这句抽成 JSON：到点的事（做什么、什么时候、重不重复、私聊还是群里）/ 没说时间的答应 / 取消 / 改时间 / 一段时间的约束。
- 抽出来的逐项核对，对不上的一律不进表：它抄的那句话得真在机器人的话里；时间得是原话里说了的（模型自己编的时间不算，降成没说时间的答应）；时间由插件自己算（模型只负责把「明早 8 点」这几个字抄出来）；「每天 / 私聊」也得是原话里说了的；取消 / 改只认这个人自己挂着的编号（管理员能改这个对话里所有的）。

**2. 到点的事（承诺表）**

- 每条记着：谁、在哪（群 / 私聊）、做什么、什么时候（一次 / 每天 / 工作日 / 每周 / 每月 / 每年）、怎么发（群里 @ / 私聊）、状态（等着 / 做了 / 没做成 / 取消）、原话出处（他说的、它回的）。
- 每人同时最多 5 件、每天新加 10 件（按「谁让定的」算，管理员不限）；同一个人、同一个对话、时间差 10 分钟以内的算同一件：「提醒他起床」「叫他起床」不会到点 @ 他两次，机器人复述一遍「记着呢明早 8 点叫你」也不会多记一条，只更新说法（每天的和一次的各算各的）。
- 后台每 20 秒看一次。到点先看发不发得出去（NapCat 连着没有、他是不是好友、机器人是不是被禁言 —— 这一步不叫模型），再把这件事的状态给模型（谁、哪天答应的、原话、现在几点、晚了多久、它这会儿是不是在睡觉），它用自己的话写一句，插件发到那个对话、群里前面 @ 那个人；写好的那句存在这件事上，没发出去的重试只重发。发出去的这句也记进对话记录。同一个地方两条至少隔 20 秒。模型叫不通时发一句「（系统提示）到点了：……」（能关）。

**3. 每轮给模型的状态**（只给这一轮的临时段：不进聊天记录、不改系统提示，所以不破坏缓存）

只写事实：答应过这个人、还没做的事（编号、时间、怎么发）；别的群 / 私聊里还有几件（只说件数，不带内容）；两小时内刚做过的（「几点已经按约定发过了」）；欠着的道歉；没说时间的答应；没记上的；他满了没有；这个对话里正在生效的约束；它刚「回来」（说了什么、多久、谁叫醒的）；插件能做到 / 做不到什么（只会到点发消息，不会打电话、转账、替人私聊别人、去别的群发）。不写示范句、不写「你可以说」、不定语气 —— 怎么说是模型自己的事。

**4. 一段时间的约束**（每个群、每个私聊各算各的）

| 它说了 | 在那个对话里 | 没说多久时默认 |
|---|---|---|
| 我去睡了 | 一句都不回 | 夜里（23 点到 8 点）说的：睡到早上 8 点出头；白天说的：小睡 30 分钟 |
| 我先走了 / 去吃饭 / 去忙 | 一句都不回 | 45 分钟 |
| 我潜水了 / 不说了 | 一句都不回 | 25 分钟 |
| 我少说两句 | 只回 @ 它的 | 30 分钟 |
| 不理你了 | 只不回他（别人照常） | 8 分钟 |
| 不发表情包了 | 照常回，发之前拿掉表情包 | 90 分钟 |

- 它自己说了多久就按说的（3 分钟到 12 小时）；没说的按上表 ±15% 随机（真人哪有掐着表回来的）。原来的做法还会按群里热闹程度伸缩时长，插件里简化掉了，只留基础时长。
- 挡的方式：要叫模型回这条之前停掉（先替天使之心收口），所以挡下的那几条连模型都不叫、不花钱；它刚说完「我去睡了」时还在路上的回复，发出去之前也拦下。把「约束」关掉、或者某一种的时长填 0，已经生效的也马上不挡。
- 「我才不睡」「这次不发表情包」不算；跟人道晚安、叫别人去睡不算；「不理」只算不理正在说话的那个人，认不出是谁就不记。
- 到点也会照样去做提醒：它在睡觉时到点了，状态里告诉它「你这会儿在睡觉，发完接着睡」。

**5. 没说时间的答应**（「等会帮你查」「回头告诉你」）

不会到点去做（插件没法替它真去查），只在他下次来找机器人时告诉模型「你 N 分钟前答应过他……」：答应完 30 分钟以后才提、隔 90 分钟提一次、最多 3 次 / 3 天。

**存在哪**：`data/plugin_data/astrbot_plugin_fatfish_promise/promise.json`，重启不丢；文件坏了会改名留着，不拿空表覆盖。

**总开关和范围（basic）**

| 项 | 默认 | 说明 |
|---|---|---|
| `enabled` | 开 | 关掉以后整个插件不做事（表里的事留着） |
| `groups` | 空 | 只在这些群管；空 = 所有群 |
| `private` | 开 | 私聊里也管 |
| `tz` | Asia/Shanghai | 按哪个时区算时间；也认 UTC+8 这种；留空 = 服务器时间 |

**抽取（extract）**

| 项 | 默认 | 说明 |
|---|---|---|
| `provider_id` | 空 | 抽取用哪个模型；空 = 这个对话在用的那个 |
| `timeout_sec` | 30 | 抽取最多等几秒，超时这句不记 |

**到点的事（tasks）**

| 项 | 默认 | 说明 |
|---|---|---|
| `enable` | 开 | 关掉以后不记新的、到点也不发 |
| `max_pending` | 5 | 每人同时最多挂几件 |
| `max_daily` | 10 | 每人每天最多新加几件 |
| `admin_unlimited` | 开 | 管理员不限件数 |
| `grace_min` | 60 | 到点没发出去：多少分钟内补上（越隔越久地试，只重发写好的那句）；开机时过点超过这么久的不补 |
| `group_via` | at | 群里答应的到点怎么发：at = 原来的群里 @ 他；private = 私聊（发不出去退回群里 @） |
| `speak_provider_id` | 空 | 到点那句用哪个模型写；空 = 对话在用的那个 |
| `fallback` | 开 | 模型叫不通时发一句「（系统提示）到点了：……」 |
| `promise_enable` | 开 | 没说时间的答应：他下次来时告诉模型 |

**约束（hold）**

| 项 | 默认 | 说明 |
|---|---|---|
| `enable` | 开 | 关掉以后它说了去睡也照常回（已经生效的也马上不挡） |
| `sleep_nap_min` | 30 | 白天说要睡：小睡几分钟（0 = 不管睡觉） |
| `night_from` / `wake_hour` | 23 / 8 | 这个时间段里说要睡 = 睡到早上几点；两项一样 = 不分夜里白天 |
| `away_min` / `lurk_min` / `quiet_min` / `ignore_min` / `nosticker_min` | 45 / 25 / 30 / 8 / 90 | 离开 / 潜水 / 少说 / 不理 / 不发表情包 没说多久时默认几分钟（0 = 不管这一种，已经生效的也马上不挡） |
| `stated_max_min` | 720 | 它自己说了多久：最多按几分钟 |

**叫醒（wake）**

| 项 | 默认 | 说明 |
|---|---|---|
| `admin_ats` | 2 | 管理员 @ 几次叫醒（0 = 管理员也叫不醒，还能用指令） |
| `people` | 3 | 群里几个不同的真人 @ 就醒（别人家的 AI 不算人） |
| `window_min` | 5 | 上面两项、下面一项在几分钟里数 |
| `private_msgs` | 3 | 私聊里他连着发几条就醒（0 = 私聊里叫不醒） |
| `floor_min` | 2 | 刚说完几分钟内只有管理员叫得醒 |

**指令**：`/说到做到`（看机器人答应你的事）、`/说到做到 取消 <编号>`（只有本人或管理员）；管理员：`/说到做到 全部`、`/说到做到 叫醒`（让它在这个群 / 私聊里回来）。群里发的指令只列这个群的事、不带 QQ 号；`/说到做到 全部` 在群里只列本群的，跨对话的（别的群、别人私聊里的）要私聊机器人发才看得到；在群里取消一件别处答应的，回话里不带它的内容。

## 已知限制

- 只认机器人在正常回话里说的（模型回复、经过 AstrBot 发送流程的那种）。别的插件绕开流程直接发的话认不到 —— 比如活人感主动说的冷场试探 / 收尾那句「我先潜水了」不会变成约束；反过来机器人睡着时，活人感的冷场试探也不会被这个插件挡住（活人感收尾以后本来就会安静一阵）。
- 到点只会「发一条消息」：答应了「明早帮你查天气」，到点只是它用自己的话提一句，插件不会替它去查；答应打电话、转账、替人私聊别人的，插件做不到（每轮的状态里写着这些事实）。
- 只提醒正在跟它说话的那个人：阿木让它「明天提醒老王」，到点 @ 的是阿木（模型写的那句里会说清楚是什么事）。
- 「不理」只认正在说话的那个人；「不发表情包」认的是表情包插件配的图、路径里带 meme / 表情 这类字的图、QQ 标成表情包的图 —— 别的插件用别的办法发的表情包可能认不出来。
- 流式输出没仔细测过：AstrBot 开了流式时，「发送前」那一步的拦截（它刚说要走、还在路上的那条；拿掉表情包）可能管不到。
- 睡觉是按对话算的（A 群说睡了，B 群和私聊照常），不是全局的。
- 发送前拦下的那条回复，AstrBot 已经记进了对话记录（它先记、后发），所以记录里可能多一句没发出去的话。
- 时间解析是规则：说法太绕的（「下个月第二个周五」）算不出来，就不记、下一轮告诉模型没记上。光说「8 点 / 12 点半」（或者「今天 8 点」）取最近的将来：下午说「8 点」= 今晚 8 点，晚上 9 点以后说「8 点」= 明早 8 点，晚上 10 点说「12 点」= 半夜 0 点。
- 「明确发不了」靠 NapCat 的好友列表和「机器人被禁言到几点」来判断，查不到时当成能发，发的时候再按 QQ 的报错分（报错里认不出原因的按「过会儿再试」算）。
- 重启时正在后台抽取的那一句会丢（只丢那一句）；「同一个地方隔 20 秒」的记录在内存里，重启后从头算。
